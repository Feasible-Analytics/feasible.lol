That's 3,377 bytes gzipped, it carries `defer` so it never blocks rendering, and it sets no cookies. On most platforms the whole installation is pasting it into one field or one file.

The pages below name that field or file for each platform, and the one thing each one hides — the plan tier that gates the code-injection box, the template that gets overwritten on the next update, the preview that never runs your code.

If you're on something that isn't here, [the install docs](/docs/installation/) cover the general case, and [where do I put the tracking script?](/help/where-do-i-put-the-tracking-script/) is the two-minute version.
