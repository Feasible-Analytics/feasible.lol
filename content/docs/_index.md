Everything here is public. No login, no gated PDF, no "contact us for the API docs."

If you're setting up for the first time, start at [installation](/docs/installation/) and stop when
it works. Most people never need the rest. If you're evaluating, [metric definitions](/docs/metrics/)
and [privacy and GDPR](/docs/privacy/) are the two that tell you whether this is the right tool.

Shorter answers to common questions live in the [help center](/help/). The feature list is on
[features](/features/), and what it costs is on [pricing](/pricing/).
